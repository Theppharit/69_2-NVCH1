# เว็บไซต์ วิทยาลัยอาชีวศึกษานครราชสีมา (Django + Tailwind CSS)

โครงสร้างหน้าเว็บอ้างอิงแนวเลย์เอาต์ของเว็บมหาวิทยาลัย (แถบประกาศ, เมนูดรอปดาวน์, สไลด์แบนเนอร์,
ลิงก์ด่วน, ข่าวเด่น, แถบสถิติ, แผนกวิชา, ท้ายเว็บ) แต่ใช้ชื่อ สี และเนื้อหาของวิทยาลัยเอง
ข้อความและตัวเลขทั้งหมดที่ใส่มาให้เป็น **ข้อมูลตัวอย่าง** แก้ไขได้ในหน้าแอดมิน

## สิ่งที่ต้องมีในเครื่อง
- Python 3.10+  (https://www.python.org/downloads/ — ติ๊ก "Add Python to PATH")
- Node.js 18+   (https://nodejs.org/)

## ติดตั้ง (ครั้งเดียว)
- Windows: ดับเบิลคลิก `setup.bat`  (หรือรันใน Command Prompt)
- macOS/Linux: `bash setup.sh`

สคริปต์จะ: สร้าง virtualenv → ติดตั้ง Django/Pillow → ติดตั้ง Tailwind CSS (npm) → build CSS →
สร้างฐานข้อมูล SQLite (`db.sqlite3`) → ใส่ข้อมูลตัวอย่าง → สร้างแอดมิน `admin / admin1234`

## รัน
- Windows: `run.bat`  (เปิด Tailwind watch + Django server)
- เปิดเว็บ: http://127.0.0.1:8000/
- เปิดแอดมิน: http://127.0.0.1:8000/admin/  — **เปลี่ยนรหัสผ่านทันที**

## ระบบแอดมิน (แก้ไขเนื้อหาหน้าเว็บ)
| เมนูในแอดมิน | ควบคุมส่วนใด |
|---|---|
| ตั้งค่าเว็บไซต์ | ชื่อ โลโก้ ข้อความแนะนำ ที่อยู่ เบอร์โทร โซเชียล แผนที่ ท้ายเว็บ |
| เมนูนำทาง | เมนูหลัก/เมนูย่อย ลำดับ เปิด-ปิด |
| แบนเนอร์สไลด์หน้าแรก | รูป ข้อความ ลิงก์ ลำดับ |
| ลิงก์ด่วนหน้าแรก | ปุ่มไอคอนใต้แบนเนอร์ |
| ประกาศ | แถบประกาศด้านบนสุด |
| ข่าวประชาสัมพันธ์ / หมวดข่าว | ข่าว รูปปก ข่าวเด่น |
| แผนกวิชา | หน้าแผนกวิชา |
| หน้าเนื้อหาทั่วไป | เช่น ประวัติวิทยาลัย (URL: `/page/<slug>/`) |
| ตัวเลขสถิติ | แถบสีน้ำเงินกลางหน้าแรก |
| ข้อความติดต่อ | ข้อความที่ผู้เยี่ยมชมส่งจากหน้าติดต่อเรา |

ข้อมูลทั้งหมดเก็บใน SQLite (`db.sqlite3`) รูปที่อัปโหลดอยู่ในโฟลเดอร์ `media/`
ช่องเนื้อหาข่าว/หน้า รองรับ HTML (ใช้ `|safe` — ให้เฉพาะผู้ดูแลที่ไว้ใจได้เข้าถึงแอดมิน)

## ปรับแต่งสี/ดีไซน์
แก้สีใน `tailwind.config.js` (ชุดสี `brand` และ `accent`) แก้เทมเพลตใน `templates/`
แล้วรัน `npm run watch` ค้างไว้ CSS จะ build ใหม่อัตโนมัติ

## ก่อนขึ้นเซิร์ฟเวอร์จริง
ตั้ง `DEBUG = False`, เปลี่ยน `SECRET_KEY`, กำหนด `ALLOWED_HOSTS`, รัน `python manage.py collectstatic`
และเสิร์ฟ `media/` ผ่าน web server
