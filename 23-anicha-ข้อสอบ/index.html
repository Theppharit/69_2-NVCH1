Key Partners
  • ร้านเบเกอรี่ / คาเฟ่ / ซูเปอร์มาร์เก็ต
  • องค์กรด้านสิ่งแวดล้อม & NGO
  • สมาคมผู้ประกอบการร้านอาหาร
Key Activities
  • พัฒนาแพลตฟอร์ม Web App
  • จัดหาและบริหารพันธมิตรร้านค้า
  • รณรงค์การลดขยะอาหาร
Key Resources
  • ระบบฐานข้อมูลและ Server
  • ทีมพัฒนาซอฟต์แวร์
  • แบรนด์และเครือข่ายร้านค้า
Value Propositions
  • เปลี่ยนวัตถุดิบส่วนเกินเป็นรายได้ให้ร้านค้า
  • ผู้บริโภคได้สินค้าคุณภาพดีในราคาถูก 50-70%
  • ลดขยะอาหารและ CO₂ อย่างวัดผลได้
  • แดชบอร์ดคำนวณ Eco Impact แบบเรียลไทม์
Relationships
  • ระบบสะสมคะแนน Eco-Points
  • ระบบรีวิวและเรตติ้งร้านค้า
Channels
  • Responsive Web Application
  • Social Media (IG, TikTok, FB)
Customer Segments
  • ผู้ขาย: ร้านอาหาร/คาเฟ่ที่ต้องการลดขยะอาหาร
  • ผู้ซื้อ: นักศึกษา คนทำงาน และกลุ่มผู้ตระหนักเรื่องสิ่งแวดล้อม
Cost Structure (โครงสร้างต้นทุน)

ค่าพัฒนาระบบและ Server, ค่าการตลาดและประชาสัมพันธ์, ค่าการดำเนินงานและดูแลพันธมิตรร้านค้า

Revenue Streams (กระแสรายได้)

ค่าคอมมิชชันจากการขายสินค้าผ่านแพลตฟอร์ม (Transaction Fee 10-15%), ค่าโฆษณา Banner สำหรับร้านค้าที่ต้องการโปรโมต

1

Empathize

สำรวจพบว่าร้านเบเกอรี่และคาเฟ่ทิ้งอาหารเหลือเฉลี่ย 3-5 กิโลกรัม/วัน ขณะที่นักศึกษาส่วนใหญ่ต้องการประหยัดค่าใช้จ่ายอาหาร แต่ไม่มีช่องทางเข้าถึงสินค้าดีลลดราคา

2

Define

โจทย์ปัญหา: "ทำอย่างไรให้ร้านค้าสามารถเปลี่ยนสินค้าส่วนเกินเป็นรายได้ และให้ผู้บริโภคเข้าถึงอาหารอร่อยในราคาประหยัด เพื่อลด Food Waste ได้อย่างยั่งยืน"

3

Ideate

คิดค้นฟีเจอร์ "กล่องสุ่มเบเกอรี่ (Surprise Box)", ระบบค้นหาตามพิกัด (Location-based) และตัวคำนวณการลดก๊าซเรือนกระจก (Carbon Saved Calculator)

4

Prototype

ออกแบบและพัฒนาเว็บไซต์ต้นแบบ EcoLoop ด้วย HTML, Tailwind CSS และ JavaScript รองรับการแสดงผลทุกอุปกรณ์ (Mobile First)

5

Test

ทดสอบการใช้งานระบบจองสินค้าจำลอง การกรองประเภทสินค้า และการแสดงผล Impact Dashboard เพื่อนำข้อติชมมาปรับปรุง UX/UI
